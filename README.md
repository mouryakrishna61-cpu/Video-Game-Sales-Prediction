# Video Game Sales Analysis and Prediction

## Project Overview
This project focuses on analyzing video game sales data using Exploratory Data Analysis (EDA) and Machine Learning.

The objective is to explore historical video game sales, identify patterns across different regions, platforms, genres and publishers, and build a Machine Learning model to predict global sales.

## Dataset
- Dataset: Video Game Sales Dataset
- Total Records: 16,598
- Target Variable: `Global_Sales`

## Machine Learning
A regression model was developed to predict `Global_Sales` using the prepared video game sales dataset.

The trained model and supporting preprocessing files were saved using Pickle for future use.
